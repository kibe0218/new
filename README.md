# 目的・方法

- 検知対象物
とりあえず時間がないので、今あるP制御のみの制御で異常判定を行う

- 異常を作り出す方法
・冷凍機の後ろの毛布を被す
・ドアを少し開放する
・フィードバックゲインを変える

- 期待される結果
・複数の温度帯で異常を検知
・”異常を作り出す方法”で正しく異常を検知する
・異なるフィードバックゲイン間で特徴量を同じにした上でモデルを作る
　→正しいモデルが生成できたら有用性を示せる

# ファイルについて

- preprocessing.py
・生の温度データを機械学習で使える数値に変換

- train.py
・正常データを使ってOCSVMを学習

- predict.py
・未知のデータを入力して異常判定
